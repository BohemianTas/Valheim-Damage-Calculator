Valheim: ดาเมจมอนสเตอร์ที่ผู้เล่นได้รับ และเงื่อนไข parry

คำนวณสดในหน้านี้จากข้อมูลที่ดึงจากไฟล์เกม ปรับค่าด้านล่างแล้วทุกตารางและกราฟจะเปลี่ยนตาม ชื่อมอนสเตอร์ ท่า และโล่เป็นภาษาอังกฤษตามในเกม

ดาวมอนสเตอร์
resistance ที่ใช้ (ชุด + status effect + กำหนดเอง)ไม่มี
resistance เพิ่มเติม
status effect ในเกม (ติ๊กได้หลายตัว ชี้ที่ชื่อเพื่อดูค่า)
กำหนดเองรายประเภท (ใช้ทับเป็นลำดับสุดท้ายตาม ShouldOverride)
รวมค่าแบบเดียวกับเกม: ชุด → status effect → กำหนดเอง แต่ละค่าแทนค่าเดิมเมื่อ “ดีกว่า” (ไม่คูณกัน) · ค่าที่เลือกเก็บใน URL (#) ส่งลิงก์ไปเครื่องอื่นได้

คลิกหัวคอลัมน์เพื่อเรียง คลิกแถวเพื่อเปิดในแท็บ “ดูท่าเดียว” ข้อมูลเกมไม่ได้บอกว่าท่าไหนเป็นท่าหลัก ตัวกรองจึงเลือกได้แค่มอนสเตอร์หลัก

HP ที่เสียต่อ hit เทียบกับเกราะ 0–150 (ไม่ block)

ของที่ใช้ block ทุกชิ้นทุกระดับ: parry ท่านี้ได้ไหม

ระดับที่ block power เท่ากันรวมเป็นแถวเดียว (อาวุธส่วนใหญ่มี blockPowerPerLevel = 0)

ช่วงเวลา

ตอนเข้า biome = ใช้ของที่ทำจากวัตถุดิบของ biome ก่อนหน้าได้ทั้งหมด ตอนเคลียร์ = ใช้วัตถุดิบของ biome นี้ได้แล้ว ระดับ ★ คือระดับสูงสุดที่ตีได้ที่สถานีปกติ (เลเวลสถานีต้องถึง และไม่ใช้ Forge of Potential) เกราะเลือกจากชุดที่ ดาเมจรวมของทุกท่าของมอนสเตอร์หลัก (ไม่นับบอส) ที่ 0★ หลัง resistance และเกราะ ต่ำที่สุด อาหารเลือก HP สูงสุด 3 อย่าง (ค่าเต็มตอนเพิ่งกิน) โล่เลือกตัวที่ parry ผ่านมากที่สุดที่ Blocking 0 ตัวเลขในการ์ดคำนวณสดด้วยสูตรเดียวกับตาราง ที่ Combat Very Hard ผู้เล่นคนเดียว และดาวมอนสเตอร์ตามที่เลือกในแผงด้านบน

ส่วนที่เขียนด้วยมือ: วัตถุดิบดิบ → biome (ดูตารางท้ายแท็บ) และรายชื่อมอนสเตอร์หลักต่อ biome ส่วนค่าเกราะ resistance set bonus อาหาร สูตร crafting สถานีและเลเวลสถานี อ่านจากไฟล์เกม

ตารางวัตถุดิบ → biome (เขียนด้วยมือ)

ลองกับค่าที่ตั้งไว้ตอนนี้

ใช้ท่าที่เลือกตรงนี้หรือในแท็บ “ดูท่าเดียว” กับค่าในแผงตั้งค่าด้านบน (เกราะ, max HP, Blocking, โล่, ระดับ, ดาว, ผู้เล่น, Combat, resistance) เปลี่ยนค่าแล้วทุกขั้นคำนวณใหม่ทันที

สูตรที่หน้านี้ใช้

ตัวอย่างใต้แต่ละสูตรใช้มอนสเตอร์ ท่า โล่ เกราะ และอาหารจริงจากไฟล์เกม ตัวเลขคำนวณตอนเปิดหน้าด้วยสูตรเดียวกับตาราง ที่ Combat Very Hard (×2) ผู้เล่น 1 คน และดาเมจสุ่มได้ค่าสูงสุด ตรงกับไฟล์ md

  1. ดาเมจที่เข้ามา = ค่าในไอเท็ม (m_damages) × m_damageMultiplier × สุ่ม √Rand(0.75, 1) × (1 + 0.5 × ดาว) × (1 + (ผู้เล่น − 1) × 0.04) × enemydamage/100
    จำนวนผู้เล่นนับเฉพาะคนที่อยู่ในระยะ 100 m และไม่เกิน 5 (Game::GetPlayerDifficulty) ส่วน AoE ที่เกิดจาก m_spawnOnTrigger ใช้ดาเมจของ AoE เองและไม่คูณดาว (ป้าย ★✗)
  2. เกราะ (DamageTypes::ApplyArmor): รวมดาเมจทุกประเภทเป็นค่าเดียวก่อน 
    ถ้า เกราะ < ดาเมจ/2 : เหลือ = ดาเมจ − เกราะ
ไม่อย่างนั้น       : เหลือ = ดาเมจ² / (4 × เกราะ)
    จากนั้นคูณทุกประเภทด้วย เหลือ/ดาเมจ ส่วน fire, poison, spirit กลายเป็น DoT ที่ทยอยลด HP ส่วนอื่นลด HP ทันที
  3. Block and Parry (Humanoid::BlockAttack): ยกโล่กันท่าที่โดนจากด้านหน้า block ธรรมดากับ parry ใช้ขั้นตอนเดียวกัน ต่างกันแค่ค่า power และ stamina 
    block power = (blockPower + (★−1) × blockPowerPerLevel) × (1 + 0.5 × Blocking/100)
parry power = block power × timedBlockBonus     (เฉพาะของที่ timedBlockBonus > 1 และกด block ไม่เกิน 0.25 วินาทีก่อนโดนตี)

    ของที่ใช้ block (Humanoid::GetCurrentBlocker @49128): ของในมือซ้ายถ้ามี (โล่ ธนู crossbow หรือคบเพลิงที่ถือคู่อาวุธมือเดียว) ไม่อย่างนั้นใช้ GetCurrentWeapon @49024 คืออาวุธมือขวา แล้วจึงเป็นอาวุธมือซ้ายที่ไม่ใช่คบเพลิง และถ้าไม่มีเลยใช้มือเปล่า (m_unarmedWeapon) อาวุธนับตาม ItemData::IsWeapon @1169264 (OneHanded, Bow, TwoHanded, TwoHandedLeft, Torch) ส่วนเครื่องมืออย่างค้อนไม่นับเป็นอาวุธ จึง block ด้วยมือเปล่า ทุกชิ้นใช้สูตรเดียวกัน (block power, parry power, stamina) และใช้ Blocking skill เสมอ (GetSkillFactor(6) @59834) ไม่ใช่ skill ของอาวุธ อาวุธส่วนใหญ่มี blockPowerPerLevel = 0 จึง block power ไม่เพิ่มตามระดับ m_blockStaminaModifier ของของที่ถือในมือนับรวมใน modifier ของ stamina (Player::UpdateModifiers @82432) ส่วนมือเปล่าไม่นับ และบางชิ้นมี m_perfectBlockStaminaRegen ซึ่งได้ stamina คืนเมื่อ parry สำเร็จ (Club, Torch, Voidcaller)

    block ธรรมดาparry
    powerblock powerparry power = block power × timedBlockBonus
    จังหวะยกโล่ค้างไว้ได้ตลอดยกโล่ไม่เกิน 0.25 วินาทีก่อนโดน (m_blockTimer < 0.25) ถ้าช้ากว่านั้นเป็น block ธรรมดา
    stamina ต่อ hit × clamp01(ดาเมจที่กันได้ / block power) × (1 + modifier ของของที่ใส่) สูงสุด m_perfectBlockStaminaDrain = (และได้คืน m_perfectBlockStaminaRegen ของโล่ ซึ่งเป็น 0 ทุกโล่)
    tower shieldใช้ได้ไม่ได้ (timedBlockBonus ≤ 1 ยกเมื่อไรก็เป็น block ธรรมดา)
    ถ้า staggerดาเมจ stagger ที่เหลือหลังหักด้วย power ≥ × max HP → block ไม่ติด โดนดาเมจเต็ม (ดูข้อ 4) แต่ stamina ยังเสีย เพราะเกมหัก stamina ก่อนเช็ค stagger และ block จะติดต้องมี stamina เหลือมากกว่า 0
    block ไม่ได้ทั้งสองแบบโดนจากด้านหลัง (Dot(hit.m_dir, forward) > 0), ท่าที่ m_blockable = false และท่าที่ m_staggerMultiplier ≥ 100 ซึ่ง stagger ก่อนดูการ block (ข้อ 5)

    สูตร stamina จาก IL (Humanoid::BlockAttack): ดาเมจที่กันได้ = ดาเมจรวมก่อน − หลังหักด้วย power (GetTotalBlockableDamage ทุกประเภทยกเว้น chop/pickaxe) @59956–59978 · ratio = clamp01(ดาเมจที่กันได้ / power) @59980–59989 · drain = parry ? m_perfectBlockStaminaDrain : m_blockStaminaDrain × ratio @59991–60011 · drain += drain × GetEquipmentBlockStaminaModifier() (ผลรวม m_blockStaminaModifier ของของที่ใส่ เช่น Ash Cape −0.2, Player::GetEquipmentModifier(5) @116838) @60013–60025 · status effect ปรับได้ (SEMan::ModifyBlockStaminaUsage @60038) · UseStamina @60055 คูณ Game.m_staminaRate (Player::UseStamina @98849, world key staminarate ที่ Combat Very Hard ไม่ได้ตั้ง จึงเป็น 1) ทั้งหมดอยู่ก่อนเช็ค stagger (@60073–60090) · parry สำเร็จได้ m_perfectBlockStaminaRegen ของโล่ (@60583–60613)
    บัฟ Bonemass: SE_Stats::ModifyBlockStaminaUsage @218376 ทำ stamina += ค่าตั้งต้น × m_blockStaminaUseModifier () แล้ว += m_blockStaminaUseFlatValue () และ BlockAttack เรียกแบบไม่ตัดที่ 0 (argument false, SEMan::ModifyBlockStaminaUsage @209045) ถ้ามี status effect หลายตัว SEMan::ModifyBlockStaminaUsage @208992 ส่งค่าตั้งต้นตัวเดียวกันให้ทุกตัว ผลจึงบวกกัน: ค่าตั้งต้น × (1 + ผลรวม modifier) + ผลรวม flat (เช่น Berserkir Mead −0.8) ค่าที่ติดลบจึงกลายเป็น AddStamina = ได้ stamina คืนทุกครั้งที่ block หรือ parry และ parry ที่สำเร็จผ่านขั้นนี้อีกรอบ (@60637–60676)
    Very Hard ทำให้ดาเมจที่กันได้มากขึ้น แต่ ratio ไม่เกิน 1 จึงเสียไม่เกิน ต่อ hit ส่วน Blocking skill มีผลผ่าน block power เท่านั้น (power มากขึ้น ratio ลดลง) ตัวอย่างในหน้านี้ไม่ได้ใส่ของที่มี modifier

  4. Stagger: power คือ block power ตอน block ธรรมดา หรือ parry power ตอน parry (สูตรในข้อ 3 Block and Parry) เกมใช้ power นี้แทนค่าเกราะในสูตรเดียวกับข้อ 2 เพื่อหักดาเมจที่เข้ามา แล้วเอาดาเมจ stagger ที่เหลือ (blunt + slash + pierce + lightning) ไปเทียบกับ × max HP ถ้า ≥ จะ stagger และ การ block ไม่ติดเลย ผู้เล่นโดนดาเมจเต็ม ถ้าไม่ stagger ดาเมจที่โดนจะเหลือเท่าส่วนที่หักด้วย power แล้ว และยังหักด้วยเกราะที่ใส่ต่ออีกรอบ (คอลัมน์ “หลัง parry”) 
    power ขั้นต่ำ (r = θ·T/S, θ = ×HP, T = ดาเมจรวม, S = ส่วน stagger)
  S = 0 หรือ r ≥ T  → power เท่าไรก็ได้
  T/2 ≤ r < T      → power > T − r
  r < T/2          → power > T² / (4r)
  5. ท่าที่ m_staggerMultiplier ≥ 100 ทำให้ stagger ทันทีก่อนดูการ block ท่าที่ m_blockable = false block และ parry ไม่ได้ และโดนจากด้านหลังก็ block ไม่ได้
  6. Resistance (HitData::ApplyModifier) คูณดาเมจแต่ละประเภท หลัง การ block และ ก่อน เกราะ: 
    Resistant ×0.5   VeryResistant ×0.25   SlightlyResistant ×0.75   Immune ×0
Weak ×1.5        VeryWeak ×2           SlightlyWeak ×1.25        Ignore → 0
    ค่าที่ใช้มาจากเสื้อ กางเกง หมวก ผ้าคลุม ตามลำดับ แล้วตามด้วย set bonus และ status effect แต่ละอันแทนค่าเดิมเมื่อ “ดีกว่า” ตาม DamageModifiers::ShouldOverride (เช่น Resistant ไม่ถูก Weak ทับ, VeryResistant ไม่ถูก Resistant ทับ) frost ที่เป็น Resistant, VeryResistant หรือ SlightlyResistant ทำให้ไม่โดน Freezing (Player::UpdateEnvStatusEffects)

    บัฟ Bonemass (Forsaken power, ติ๊กได้ในเมนู “resistance เพิ่มเติม” ของแผงตั้งค่า พร้อม status effect อื่นในเกมที่มี resistance และ resistance ที่กำหนดเองรายประเภท): บัฟเข้ามาในขั้น resistance เท่านั้น: Character::RPC_Damage เรียก BlockAttack @19107 ก่อน แล้วจึง GetDamageModifiers @19447 → ApplyResistance @19457 → หักด้วยเกราะที่ใส่ (GetBodyArmor / ApplyArmor @19471–19481) บัฟจึงไม่ช่วยเรื่อง parry หรือ stagger (block power, parry power และ power ขั้นต่ำเท่าเดิม) ช่วยแค่ดาเมจที่โดนหลังจากนั้น (ต่างจาก m_staggerModifier ของ status effect เช่น Forsaken power ของ Fader ที่ Character::AddStaggerDamage @21340 → SE_Stats::ModifyStagger @218417 คูณดาเมจ stagger ตอน block ด้วย 1 + m_staggerModifier หน้านี้คิดเป็นเกณฑ์ stagger ÷ (1 + ผลรวม) เมื่อติ๊ก) วิธีรวมกับ resistance ของชุด: GetDamageModifiers @19760 เริ่มจากค่าของตัวละคร → ของชุด (ApplyArmorDamageMods) → status effect ทุกตัว (SEMan::ApplyDamageMods @206112 → SE_Stats::ModifyDamageMods @217936 → DamageModifiers::Apply → ApplyIfBetter @1203431) คือ เลือกค่าที่ดีกว่า ไม่ได้คูณกัน เช่น poison Resistant จาก Root Mask ไม่ถูก SlightlyResistant ทับ ส่วน blunt ที่ชุดไม่มีจะได้ SlightlyResistant จากบัฟ บัฟไม่เพิ่มเกราะ (m_addArmor , m_armorMultiplier ซึ่ง SE_Stats::ModifyArmorMods @218492 ข้ามเมื่อเป็น 0)

  7. max HP = (m_baseHP) + HP ของอาหาร 3 อย่าง (Player::GetTotalFoodValue) อาหารแต่ละอย่างให้ health × (เวลาที่เหลือ/เวลาทั้งหมด)^0.3 (Player::UpdateFood) จึงเต็มตอนเพิ่งกิน เหลือ 81% ตอนผ่านไปครึ่งเวลา และ 50% ตอนเหลือเวลา 10%

สมมติฐาน

  • ใช้ดาเมจสูงสุดที่สุ่มได้ (มอนสเตอร์ตีแรง 86.6–100% ของค่าในหน้านี้ แบบสุ่ม ดูตัวอย่างในสูตรข้อ 1)
  • ผู้เล่นไม่มี resistance (ไม่มีเกราะ ยา หรือ mead ที่ให้ resist) จนกว่าจะกด “ใช้ชุดนี้ในตาราง” ในแท็บแนะนำ ซึ่งจะใส่ resistance ของชุดนั้น (ดูช่อง resistance ในแผง) และไม่มี status effect ที่แก้ stagger หรือ parry
  • แถบ stagger ว่างอยู่ ถ้าโดนตีหลายครั้งภายใน 5 วินาทีจะสะสม และ stamina ยังไม่หมด (parry ไม่เสีย stamina, block ธรรมดาเสีย × สัดส่วนที่กัน)
  • world level = 0 และไม่มี modifier อื่นนอกจาก Combat
  • biome จัดเองจากชื่อ prefab (มอนสเตอร์ที่ไม่ได้จัดอยู่ใน “อื่นๆ”) ส่วน max HP ในการตั้งค่าใส่เองได้
  • ท่าที่เป็น SpawnAbility (เรียกมอนสเตอร์หรือสิ่งของอื่น) ไม่ได้คำนวณ AoE ที่ลดดาเมจตามระยะใช้ค่าเต็ม ท่าที่มีป้าย ⟳ ตีซ้ำทุกช่วงเวลาที่บอกขณะยืนอยู่ในพื้นที่
